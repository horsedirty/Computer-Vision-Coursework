# 视频防抖（Python + OpenCV 传统算法）

基于经典计算机视觉的视频防抖流水线，**不使用深度学习**。为追求运行效率（评分含运行时间 40%），
核心算法采用 C++ 后端的 OpenCV 实现，KLT 跟踪 + 降采样估计在 1080P 上可达近实时。

## 三阶段流水线

| 阶段 | 文件 | 做什么 |
|------|------|--------|
| ① 运动估计 | `motion_estimation.py` | 降采样 + `goodFeaturesToTrack` + KLT 光流 + `estimateAffinePartial2D`(RANSAC) 估计逐帧 4 自由度相似变换（平移/旋转/缩放）。失败沿用上帧运动，不跳变 |
| ② 运动平滑 | `smoothing.py` | 矩阵连乘累积绝对轨迹 → 分解参数 → 高斯零相移低通 / L1 最优路径平滑，分离主动运动与抖动 |
| ③ 帧合成 | `synthesis.py` | 矫正矩阵 `W=S·A⁻¹` 做 `warpAffine` + 中心 zoom-in 去黑边 + USM 锐化 + 编码 |
| 评测 | `metrics.py` | 有效防抖时长占比：对输出重估运动，高频残差 < 阈值的帧视为"平稳" |

## 安装

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## 用法

```bash
# 基本：高斯平滑
python stabilize.py input.mp4 -o output.mp4

# L1 最优路径 + 自评有效防抖占比
python stabilize.py input.mp4 -o output.mp4 --smooth l1 --eval

# 常用参数
#   --proc-scale 0.5   运动估计处理分辨率（越小越快，1080P 建议 0.5）
#   --radius 30        高斯平滑半径（越大越稳、越牺牲主动运动跟随）
#   --crop-ratio 0.05  去黑边的中心放大比例
#   --no-sharpen       关闭锐化
```

## 当前实测（720p 合成抖动视频，335 帧）

| 视频 | 有效防抖占比 前→后 | 平均抖动(px) 前→后 | 自适应放大 |
|------|------|------|------|
| handheld_walking | 0.6% → **75.8%** | 7.42 → 0.75 | 1.055x |
| quick_panning | 1.2% → **64.5%** | 8.96 → 0.91 | 1.074x |
| static_standing | 47.8% → **94.0%** | 1.18 → 0.41 | 1.020x |
| bumpy_riding（剧烈+运动模糊，极端工况） | 0.0% → 1.8% | 68.4 → 3.87 | 1.234x |

运动估计 ~2.8 ms/帧（含前后向校验），全流程 ~3 s/段。

## 关键技术点

- **前向-后向光流校验**：剔除回跳误差大的不可靠跟踪点，内点率提升到 0.96–1.00。
- **自适应裁剪**：按各帧矫正量自动算出"刚好藏住黑边"的最小放大倍数（高分位数 + 上限），
  平稳视频只裁 ~2%，剧烈视频自动加大，肉眼看不到黑边又尽量保留画面。
- **半分辨率估计**：`proc-scale 0.5` 对运动模糊更鲁棒（满分辨率反而被模糊干扰），且更快。
